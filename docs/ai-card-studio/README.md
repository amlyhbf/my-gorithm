# 맘고리즘 AI 카드 스튜디오 V2 (개발 브랜치)

기준: feat/content-manager-v1
개발 브랜치: feat/ai-card-studio-v2
**운영 사이트 및 기존 Vercel 배포는 수정하지 않았습니다.**

## 1. 무엇을 만들었나

- 승민이의 후보 CSV 32개를 선택해 목록에서 관리
- 기존 카드 열람 모양의 고정 레이아웃에서 제목·추천 이유·핵심 요약 3개·본문 섹션 2~8개 직접 편집
- 위키백과 URL에서 원문 텍스트·대표 이미지를 가져오는 로컬 전용 서버
- 명시적 확인 후 OpenAI Responses API Structured Outputs로 카드 초안 생성
- Wikimedia 문서 대표 이미지 우선 사용, 별도 버튼과 비용 승인 후 선택형 이미지 생성
- 링크·원문 대조·이미지 이용 조건 확인 후 수동 승인
- 검토 내역 임시 저장 및 JSON 백업, 승인된 카드만 개발용 JSON 내보내기
- 기존 개발용 카드 변환기와 호환. main 병합이나 사이트 자동 게시 기능 없음.

## 2. Windows PowerShell 설치 및 로컬 실행

cd $HOME
git clone --branch feat/ai-card-studio-v2 --single-branch https://github.com/amlyhbf/my-gorithm.git my-gorithm-ai-studio
cd .\my-gorithm-ai-studio
npm.cmd ci
npm.cmd run studio

브라우저로 다음 주소를 열어요.

http://127.0.0.1:4178/tools/card-studio.html

별도 GitHub 저장소, 운영 Firebase 및 Vercel에는 영향이 없습니다. 이 서버는 127.0.0.1 루프백 주소에서만 동작하며 공용으로 배포하면 안 됩니다. API 키가 없어도 CSV 업로드, 직접 편집, 검토·승인·내보내기는 사용할 수 있습니다. 키 없이 위키백과 원문/이미지 찾기를 이용하려면 인터넷 연결이 필요합니다.

## 3. AI 이용 조건과 비용

ChatGPT Plus와 API 과금은 별도입니다. 담당 교사·팀 관리자에게 승인받은 API 프로젝트와 키만 로컬 환경변수 OPENAI_API_KEY로 전달하세요. 비밀키를 HTML/JS, CSV, GitHub, 화면 캡처에 직접 붙여넣지 마세요.

초안 생성은 기본 모델 gpt-6-luna로 Responses API에 비용이 발생하는 요청을 보냅니다. AI 이미지 생성은 기본 비활성이고, 담당자의 비용 승인 후 환경변수 STUDIO_ENABLE_IMAGE_GEN=1로 활성화할 수 있습니다. 기본 이미지 모델은 gpt-image-2.5-flare입니다.

유료 API 호출은 사용자 버튼 클릭과 확인 대화상자를 통과한 경우에만 실행됩니다. 한 서버 실행 기준 기본 텍스트 12회·이미지 2회 제한이 적용됩니다. 서버를 재시작하면 횟수 제한도 초기화되므로, 실제 금액 상한은 API 관리 콘솔에서 추가 설정해야 합니다. 모델 계정 권한·요금은 별도 확인이 필요합니다.

## 4. 사용법

1. CSV 선택: 맘고리즘_콘텐츠후보_2026-10-29(1).csv (32개).
2. 후보 카드를 선택하면 가운데 기존 카드 열람 템플릿이 열림.
3. 원문·이미지 찾기로 Wikipedia 내용을 확인하고 대표 이미지 후보를 불러오기.
4. AI 초안 작성 버튼으로 제목·요약·추천 이유·핵심 3개·본문 2~4개 생성.
5. 실제 카드 화면에서 텍스트를 클릭해 수정하고 이미지 링크 변경.
6. 저작자·라이선스 등 이미지 출처 메모 작성, 내용·링크·이용 조건을 직접 확인.
7. 수동 승인. 승인된 카드만 JSON으로 내보내기.
8. 이후 별도의 개발 브랜치에서 변환기 실행 및 검증 후 등록 여부 결정.

중간 편집 내용은 브라우저 localStorage에 저장합니다. 팀원이 다른 PC로 이동하거나 브라우저를 초기화하기 전 검토 JSON을 내려받아 백업해야 합니다.

## 5. 이미지 처리 주의사항

원문 대표 이미지 자동 선택은 저작권을 자동 확인한다는 뜻이 아닙니다. 각 Wikimedia 파일의 저작자, 출처, 라이선스, 표시 요건을 확인하고 이미지 출처 메모에 기록해야 승인할 수 있습니다.

선택형 AI 이미지는 public/studio-generated 폴더에 로컬 PNG로 저장되며 Git에서 제외됩니다. 로컬 경로는 운영 사이트의 영구 URL이 아니므로, 배포 전 별도 이미지 저장소에 업로드하고 HTTPS 주소를 확보해야 승인할 수 있습니다. 생성 이미지는 설명용 일러스트로 취급하고 사실을 증명하는 사진처럼 제시하지 마세요.

신규 카드의 이미지 출처 메모는 기사 열람 화면에도 표시하도록 해당 개발 브랜치에서 UI를 보완했습니다. 다만 표시 내용이 개별 라이선스 의무를 충족하는지는 별도 확인해야 합니다.

## 6. 자동 테스트 명령

npm.cmd run test:studio
npm.cmd run test:content
npm.cmd run test:feed
npm.cmd run build

스튜디오 서버가 실행 중일 때 별도 PowerShell에서:
npm.cmd run test:studio:browser

브라우저 테스트는 테스트 CSV 1개로 기존 카드 열람 템플릿, 직접 편집, 수동 승인, 내보내기, 새로고침 복구를 검사하고 유료 AI 요청은 하지 않습니다.

## 7. 개발 데이터 변환

승인된 카드 JSON을 개발 복사본 안에 두고:
node tools/merge-approved-content.mjs .\mamgorithm-approved-cards.json

기본 실행은 tools/content-data.preview.js 미리보기만 만들며 data.js에는 반영하지 않습니다. 실제 반영은 별도 승인, 테스트, --apply 옵션이 필요합니다.

## 8. 정확한 작업 상태

확인된 사항: GitHub 개발 브랜치에 로컬 서버, 위키백과 조회, OpenAI API 호출부, 시각적 템플릿 편집기, 승인 기능 및 테스트 코드를 작성하여 저장했습니다.

아직 확인되지 않은 사항: 전체 로컬 빌드·브라우저 통합 테스트 실행, 실제 OpenAI 유료 API 호출 성공, 이미지 생성 실호출, 32개 원본 품질 검증, 카드 실제 등록, 운영 Firebase/Vercel 반영. 개발 완료와 테스트/배포 완료를 혼동하지 마세요.

초기 목표는 'URL 한 개 → AI 카드 초안 → 사람이 편집·검토 → 승인 JSON'이며 32개를 무인으로 일괄 생성하는 기능은 이 단계에서 구현하지 않았습니다.
