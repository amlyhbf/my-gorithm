# V4 자체 검토 기록

## 검토 과정과 실제 수정

1. 처음 핵심 스틸을 출력했을 때 넓어지는 리본의 일부가 좌우 경계 밖으로 나갔다.
   모핑의 너비·중심 오프셋에 맞춰 궤적을 안전영역으로 제한하고 다시 렌더링했다.
2. 트랙이 흰 손잡이 위를 가리는 것을 확인했다.
   Rive의 first-declared-on-top 규칙에 맞춰 손잡이 그룹을 앞으로 옮겼다.
3. 전체 저해상도 시안에서 분야명이 도형 뒤로 가려졌다.
   도형 내부의 타이포그래피를 최상위로 옮기고 전체 시안을 다시 출력했다.
4. 카드 교체 시 축소의 기준점이 화면 원점이어서 타일이 함께 왼쪽으로 흔들렸다.
   각 카드의 로컬 원점을 자체 중심으로 바꾸고 저해상도 전체 시안에서 확인했다.
5. 마지막 브랜드가 너무 높은 위치에 있었다.
   타이포그래피와 아래 UI의 간격을 다시 잡고 최종 레이아웃을 별도로 네이티브 렌더했다.
6. 고해상도 모핑에서 리본 가운데 굽힘이 의도보다 약하게 보였다.
   긴 가장자리의 cubic in/out 핸들에도 곡률을 넣어 S자 리본이 펴지는 실제 패스 변형을 만들었다.
   이전 최종 렌더 작업을 중지하고 임시 프레임을 비운 뒤 개선본을 전량 다시 렌더링했다.

전체 저해상도 영상은 구성·시간 검토용 기록이며, 마지막 레이아웃과 곡률의 최종 수정까지 반영된 납품본은
고해상도 MP4와 최종 프레임으로 만든 스토리보드다. 초안 MP4를 최종 영상으로 안내하지 않는다.

## 검증 근거 파일

- `scene.rml`: 같은 벡터 객체의 키프레임 및 상태 머신.
- `logic-snapshots.json`: 실제 함수에서 얻은 조절 상태·추천 카드 ID·순서.
- `preview/logic-verification.json`: 추천 로직 재실행·분배·패스 구조·본체 유지 검사.
- `preview/frame-audit.json`: 최종 네이티브 프레임 수·크기와 구간별 고유 PNG 해시 수.
- `preview/storyboard.png`, `morph-sequence.png`: 실제 최종 프레임 모음.
- `preview/final-*-info.json`: MP4 실측 사양.

레퍼런스 링크의 영상을 직접 시청하지 못했으며, 시청했다고 주장하지 않는다.
영화적 깊이감은 2D의 크기·겹침·시차로 표현한다. 투명 잔상은 셔터 기반 모션 블러가 아니다.
추천 타일은 실제 콘텐츠 썸네일을 복제하지 않은 분야 요약이며, 선택되는 카드의 ID와 분야·순서는 실제 로직과 일치한다.

7. S자 개선을 스토리보드 전체에 대입하니 원형에 가까운 초반 도형에서 곡선 제어점이 겹쳐 작은 돌기가 생겼다.
   긴 가장자리의 실제 길이에 맞춰 핸들 길이와 굽힘을 제한해 해결했다.
   변경된 32개 선형 키프레임 속성이 각 테마에서 7.5초 이후 동일함을 검사했다.
   8·10·13·16초를 두 테마에서 실제 재렌더링해 RGB 픽셀 차이가 모두 0임을 확인했다.
   검증된 8초 이후 프레임은 보존하고, 영향을 받은 초반 8초를 60FPS로 다시 렌더링해 모든 결과 영상을 재인코딩했다.
   시간 보간·저해상도 확대·저프레임 복제로 재렌더링을 대체하지 않았다. 근거는 `preview/cache-verified.json`이다.
