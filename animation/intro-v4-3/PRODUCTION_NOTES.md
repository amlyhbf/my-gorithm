# V4.3 제작 메모

## 바꾼 이유

V4.2의 소재·두 테마·16초를 보존하고 시간 배분과 시선 순서에 집중했다.
첫 2초의 등장 키는 보존한다. 이후 4초에 걸친 반복 우회를 덜어내고,
1.5초의 새 연결 경로로 기존 6초 위치·속도에 도착한다. 영화 파일을 배속하지 않는다.
기존 6–10초 모핑의 로컬 벡터 키와 이징은 3.5–7.5초로 그대로 이동한다.
네 행의 간격 확장은 정돈 구간의 Y 이동에만 부드럽게 더한다.

슬라이더와 피드는 각각 주인공이 되는 시간을 갖는다. 두 조절 모두 완료 뒤
조절 구간 뒤 0.25초 추가 정착을 두며, 카드 반응 동안 손잡이·벡터 트랙·수치가 고정된다.
피드는 조절 중 이전의 유효한 결과를 보여주다가 새 계산 결과로 이동한다.
계산 결과를 바꾸지 않고 영상 표시 시점만 연출한다.

## UI

눈금 29px와 브랜드 글자 크기·위치를 유지했다. 채널 카드 높이를 136→160px,
행 간격을 160→176px로 바꿨다. 눈금의 중심과 카드 하단 사이를 6→30px로 확보한다.
트랙–눈금 중심 간격은 46px로 유지하므로 손잡이에 눈금을 붙이지 않는다.
슬라이더 아래 피드는 60px 내려 마지막 카드·맞춤 피드 제목의 간격을 유지한다.
브랜드 아래에는 향후 HTML 버튼용 y1570–1770의 공간을 남긴다. 영상 안에 버튼은 그리지 않는다.

## 자체 수정

1. 초기 연결의 가속도를 그대로 이식했더니 기술 도형의 로컬 핸들이 과도하게 움직여
   윤곽이 꼬였다. 끝점 속도를 보존하되 국소적으로 소멸시키는 방식으로 바꾸고
   반 프레임 간격의 윤곽 자기교차 검사를 다시 통과했다.
2. 첫 카드 경로는 이동 중 제목이 가려졌다. 실제 카드 표면·텍스트 영역으로 경로와
   시간차·겹침 순서를 비교하여 경로를 수정했다. 반복 바운스나 강한 확대는 넣지 않았다.
   재배치 도중 카드 가장자리의 짧은 겹침은 남는다. 모든 이동 순간의 모든 글자가
   완전히 가려지지 않는다고 주장하지 않는다. 안정된 결과는 모두 읽을 수 있다.
3. 렌더용 사본에서 해당 프레임을 둘러싼 숫자 키만 남겨 공식 CLI의 재컴파일 비용을
   줄였다. 원본 RML과 최종 .riv에는 전체 키가 남는다. 시간·보간·벡터 래스터화는
   공식 Rive CLI가 처리한다. 원본/사본 네이티브 A/B의 픽셀 차이도 기록한다.
   일부 가장자리의 미세한 차이는 있으므로 완전한 RGB 동일성을 주장하지 않는다.
   V4.2에서 재사용하는 첫 2초는 별도로 원본 전체 키의 네이티브 출력과 RGB 동일성을 검사한다.

## 실제 추천 규칙

웹사이트의 calculateAllocation·buildFeedList를 그대로 격리 실행한다. 관심도는
0–100/5 단위, 시작 50/50/50/50, 최종 100/30/20/50이다. 실제 기본 피드는 계속 12개다.
영상 6장은 실제 함수의 6개 용량 결과이며 실제 12개 결과에 같은 상대 순서로 포함되는
대표 보기다. 서비스에 새 6개 설정 기능을 추가하지 않는다.
최종 실제 12개 배정은 공부6/기술2/문화1/취미3이다. 첫 반응은 기술 콘텐츠 하나를
실제 공부 콘텐츠로 교체하고, 둘째 반응은 취미·기술·문화의 순위를 재배치한다.

## 한계

공식 CLI 1.8.0의 로컬 .riv 빌드이며 계정에 업로드하거나 .rev를 내보내지 않는다.
물리 기기·웹 런타임 성능 검증과 테마 연동·첫 방문·건너뛰기·오류 대체·움직임 감소는
디자인 승인 후 별도 작업이다. 운영 사이트, 추천 코드, 콘텐츠, 사용자 저장 기능은 변경하지 않는다.

실측: 5단위 값이 먼저 안정되므로 손잡이의 마지막 유의한 이동에서 피드 반응까지는 약0.417초/0.500초다. 설계 구간 뒤 추가0.25초와 구분해 measured-attention-gaps.json에 기록했다.
