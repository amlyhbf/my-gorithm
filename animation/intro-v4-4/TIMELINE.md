# V4.3 실제 키와 V4.4 시간표

| 내용 | V4.3 | V4.4 | 유지/변경 |
| --- | --- | --- | --- |

| 기술 진입 | 0.2–0.7초 투명도 상승 | 0.250초 시작 → 1.333초 합류 | 반대쪽 교차 진입 |
| 문화 진입 | 0.4–0.9초 투명도 상승 | 0.483초 시작 → 1.433초 합류 | 부드러운 아크 |
| 취미 진입 | 0.6–1.1초 투명도 상승 | 0.683초 시작 → 1.500초 합류 | 아래쪽 짧은 곡선 |
| 모두 등장한 뒤 자유 이동 | 1.1–3.5초 | 1.5–3.9초 | 동일한 2.4초·경로·속도 |

| 공부 슬라이더 조절 구간 | 7.8–8.7초 | 8.2–9.1초 | 0.9초 그대로 |
| 첫 카드 교체 | 8.950–9.650초 | 8.867–9.567초 | 42프레임 그대로 |
| 기술·문화 슬라이더 구간 | 10.15–11.25초 | 10.55–11.65초 | 1.1초 그대로 |
| 두 번째 카드 재배치 | 11.500–12.650초 | 11.300–12.450초 | 69프레임 그대로 |
| 브랜드 등장·정리 | 13.3–14.3초 | 13.3–14.3초 | 키·위치·움직임 그대로 |
| 마지막 안정 상태 | 14.3–16초 | 14.3–16초 | UI·브랜드·버튼용 공간 그대로 |

피드는 새 입력 시각에 단순히 +24프레임 했을 때보다 각각29/36프레임 먼저 반응한다.
첫 반응은 실제 손잡이 이동의 약92.5%, 둘째는 문화88.4%/기술94.8% 지점이다.
V4.3에서 실제 손잡이가 멈춘 뒤0.417/0.500초 기다리던 것을,
V4.4에서는 마지막 유의한 이동보다0.067/0.100초 먼저 반응하는 방식으로 시험한다.

새 등장에0.4초를 배정하고 승인된 자유 이동과 모핑의 속도는 바꾸지 않는다.
남는 시간은 카드 결과를 읽는 데 사용하며 브랜드 시각과 전체16초는 유지한다.
입력 범위·관심도 값·추천 데이터·카드 경로·UI 패딩은 바꾸지 않는다.
