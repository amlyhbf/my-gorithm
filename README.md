# 맘고리즘 (My-gorithm)

> **"알고리즘의 노예가 아닌, 주인이 되는 새로운 피드"**  
> 사용자가 직접 관심 분야의 비율을 튜닝하고 제어하는 사용자 주도형 콘텐츠 추천 웹 애플리케이션

🌐 **라이브 서비스:** [https://my-gorithm.web.app](https://my-gorithm.web.app)

---

## ✨ 핵심 기능

1. **상시 고정 미니 독 & 4색 알고리즘 믹서 (Mini Dock & Mixer)**
   - 평소에는 슬림한 4색 비율 게이지 미니 바로 상태 표시
   - 위로 슬라이드 시 4개 분야(공부, 기술, 문화, 취미)를 `0% ~ 100%` 단위로 자유롭게 믹싱
   - 0% 설정 시 해당 주제는 추천 피드에서 100% 원천 배제
   - 4개 모두 0%일 때 인라인 경고 및 피드 반영 방지

2. **투명한 추천 분배 메커니즘 (Largest Remainder Method)**
   - 플랫폼의 블랙박스 중독 알고리즘 대신, 사용자가 지정한 가중치 합산 대비 상대 비율을 최대 잔여수 방식으로 계산하여 12장의 카드를 공정하게 분배
   - [내 알고리즘] 탭에서 실시간 가중치 배분표와 수식 투명 공개

3. **인앱 플레이어 & 리더 모드 (In-App Player & Reader)**
   - **영상 콘텐츠:** 16:9 유튜브 반응형 인앱 바텀시트 플레이어
   - **기사 콘텐츠:** 외부 사이트 이탈 없이 3줄 핵심 요약 및 상세 본문을 읽을 수 있는 인앱 리더 모드

4. **상용앱 수준의 인터랙션 & 피드백 시스템**
   - **실행 취소 스낵바 (Undo Snackbar):** 북마크 해제 및 보관함 비우기 시 4초 카운트다운 타이머와 함께 원상 복구 액션 제공
   - **확인 모달 다이얼로그 (Confirm Modal):** 균형 리셋 및 전체 보관함 삭제 시 안전 확인
   - **컨텍스추얼 툴팁 (Tooltip):** 계산 공식 및 믹서 팁 말풍선
   - **코치마크 스포트라이트 (Coachmark):** 첫 방문자 하단 미니 독 가이드 투어
   - **마이크로 뱃지:** 보관함 실시간 숫자 카운트 뱃지 & 신규 카드 `NEW` 뱃지
   - 모바일 환경 최적화 햅틱 피드백 (진동)

5. **알고리즘 레시피 공유 (Recipe Sharing)**
   - 내가 조절한 4개 분야 비율을 URL 쿼리 파라미터(`?s=50&t=50&c=50&h=50`)로 친구에게 바로 공유

---

## 🛠 기술 스택

- **Frontend:** Vanilla JavaScript (ES Modules), HTML5, Modern CSS (Responsive Design System)
- **Bundler:** Vite
- **Backend & Deploy:** Firebase (Hosting, Firestore, Anonymous Auth)
